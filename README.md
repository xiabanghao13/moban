# moban · 可复用工程模板

给 AI 看的「照单复刻」规格书。每份模板是一套完整机制的：设计原则、数据结构、算法伪代码、协议定义、边界情况、验收标准。把整份文档发给任何 AI，它就能在你的项目里把这套机制从零做出来，不依赖原项目的代码和语言。

| 模板 | 文件 | 解决什么问题 |
|---|---|---|
| 内容热更新 | [hotupdate-template.md](hotupdate-template.md) | 不重装程序就能更新界面/逻辑/数据（GitHub+jsDelivr 免费分发，增量下载，秒级更新，坏更新自动回退） |
| 多端数据同步 | [datasync-template.md](datasync-template.md) | 手机/电脑等多设备使用数据保持一致（本地优先，断网可用，事件溯源+LWW，最终一致） |

## 怎么用

把对应模板全文发给 AI，附一句话，例如：

> 请按这份规格书，在我的 <你的项目>（技术栈：Python 桌面 / WebView 安卓壳 / Electron……）里实现这套机制。按文档里的「验收标准」自测。

AI 可以换任何语言实现；文档里的伪代码是语言无关的，协议是纯 JSON over HTTP。
